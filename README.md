# Febin Joseph — Portfolio

A premium, responsive developer portfolio built with Next.js 14, React, TypeScript, Tailwind CSS and Framer Motion. The layout takes inspiration from the supplied reference repository, with original portfolio content and styling.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Content notes

The experience, skills, certifications, education and three featured projects are based on Febin Joseph's July 2026 resume. Project repository/demo links and screenshots were not included in the resume, so none are fabricated. Add verified links and genuine screenshots when available.
